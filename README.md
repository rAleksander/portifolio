# Renan — Portfólio Profissional

Portfólio pessoal desenvolvido para apresentar minha trajetória profissional, projetos, conhecimentos técnicos e formas de contato.

O projeto tem como objetivo servir como uma apresentação profissional para oportunidades na área de **Análise de Dados** e **Desenvolvimento Back-end**, reunindo informações sobre minha experiência, tecnologias que utilizo e projetos desenvolvidos.

## 🚀 Tecnologias utilizadas

* **HTML5** — estrutura e semântica da página
* **Tailwind CSS** — estilização e layout responsivo
* **Alpine.js** — interações e gerenciamento de estados da interface
* **JavaScript** — funcionalidades e comportamento da página
* **SVG** — ícones e elementos gráficos
* **Google Fonts** — tipografia da aplicação

### Principais fontes

* **PT Sans** — títulos e elementos de destaque
* **DM Sans** — textos e conteúdo geral

## Funcionalidades

* Layout responsivo para desktop e dispositivos móveis
* Modo claro e escuro
* Menu de navegação responsivo
* Navegação por seções através de âncoras
* Destaque automático da seção atualmente visualizada
* Animações de entrada dos elementos durante o scroll
* Efeitos de hover em botões, cards e links
* Seção de apresentação profissional
* Apresentação de serviços
* Portfólio de projetos
* Seção de avaliações
* Área de contato
* Links para GitHub, LinkedIn e e-mail
* Persistência da preferência de tema utilizando `localStorage`

## Estrutura do projeto

Atualmente, o projeto é composto principalmente por uma página HTML:

```text
portfolio/
│
├── index.html
├── renan.jpeg
└── README.md
```

O arquivo `index.html` concentra a estrutura, estilização e lógica da aplicação.

As bibliotecas externas são carregadas via CDN.

## Identidade visual

O projeto utiliza uma interface minimalista baseada em tons neutros, com destaque para as cores da identidade visual:

* **Roxo:** `#3c038c`
* **Azul:** `#08209c`

O roxo é utilizado como principal cor de destaque da interface, enquanto o azul aparece em elementos específicos.

A aplicação também possui suporte a **Dark Mode**, permitindo alternar entre os temas claro e escuro.

## Como executar

Como o projeto utiliza HTML, Tailwind CSS e Alpine.js através de CDN, não é necessário instalar dependências para executar a versão atual.

Basta clonar o repositório:

```bash
git clone https://github.com/rAleksander/raof-tech-site.git
```

Entrar na pasta:

```bash
cd raof-tech-site
```

E abrir o arquivo:

```text
index.html
```

Também é possível utilizar uma extensão como **Live Server** no VS Code para executar o projeto localmente.
